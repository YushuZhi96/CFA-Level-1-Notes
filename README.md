## 归档工作流
1. 在当前 CFA ChatGPT 会话学习知识点，讲解完说「收录这个知识点」。
2. ChatGPT 归纳知识点、核对公式，并通过已连接的 GitHub 提交对应的 Markdown。
3. 在 Obsidian 中打开已克隆的仓库。拉取最新提交后浏览。**GitHub 更新不会自动同步到尚未拉取的本地 Obsidian 库。**
4. 一知识点一文件，中英术语、LaTeX 公式、易错点、状态及日期均用统一格式。

仅记录自写总结，不大段复制付费题库原题或解析。
