# 追赶机制（GP Catch-Up）

## 一句话理解
在私募投资基金的**约定分配瀑布**中，LP 达到约定的优先收益（Preferred Return / Hurdle）后，部分后续可分配利润可能暂时较高比例分给 GP，使其累计分配“追赶”到协议约定的绩效报酬比例。

## 常见顺序（具体以基金合同为准）
1. Return of Capital：返还出资。
2. Preferred Return：向 LP 支付约定优先收益。
3. GP Catch-Up：按协议对 GP 进行追赶分配。
4. Residual Split：剩余利润按约定比例分配。

## 易错点
- 有无 catch-up、是否 100% catch-up、计算基数以及采用 whole-fund 或 deal-by-deal waterfall **都由合同决定**。
- Hurdle 不等于 GP 立刻按同一比例从全部现金流中抽成。
- 练数字题时，先列分配层级，再根据题干比例逐层计算；不能跳过优先收益直接分成。
