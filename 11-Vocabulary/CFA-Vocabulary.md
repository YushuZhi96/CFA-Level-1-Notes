# CFA 专业词汇总表（CFA Master Vocabulary List）

> 本文件是 CFA 一级唯一的专业词汇总表。后续所有科目的重要英文术语统一追加到这里，不再按科目拆分成多个单词文件。

## Ethics｜职业伦理

| English Term                                    | 中文释义               | 考试语境 / 记忆                                |
| ----------------------------------------------- | ------------------ | ---------------------------------------- |
| Moral and Ethical Principles                    | 道德与伦理原则            | Ethics 的核心含义                             |
| Code of Ethics                                  | 道德规范               | 特定群体的书面道德原则                              |
| Standards of Conduct                            | 行为准则               | 最低可接受行为标准                                |
| Obligatory Conduct                              | 必须履行的行为 / 义务       | Code of Ethics 的关键词                      |
| Forbidden Conduct                               | 禁止的行为              | Code of Ethics 的关键词                      |
| Minimally Acceptable Behavior                   | 最低可接受行为            | Standards of Conduct 的关键词                |
| Benchmark                                       | 基准 / 衡量标准          | Standards of Conduct 衡量行为的标准             |
| Law / Laws                                      | 法律                 | 由政府或有权机构制定，适用于相应司法管辖区                    |
| Soft Dollar                                     | 软美元                | 使用客户交易佣金换取研究或经纪服务                        |
| Soft Dollar Arrangement                         | 软美元安排              | 通过客户交易佣金换取研究产品或服务的安排                     |
| Brokerage Commissions                           | 经纪佣金               | 客户交易产生的佣金                                |
| Research Products and Services                  | 研究产品与服务            | 可能由合格 Soft Dollar 支付的研究资源                |
| Hard Dollar                                     | 硬美元                | 管理人直接用现金预算购买服务                           |
| Best Execution                                  | 最佳执行               | 交易执行应考虑整体执行质量与客户总成本                      |
| Mixed-Use Services                              | 混合用途服务             | 同时具有研究用途和一般经营用途的服务，需合理分摊                 |
| Professional Conduct Program (PCP)              | 职业行为计划             | CFA Institute 的职业行为监管计划                  |
| Board of Governors                              | 理事会                | 负责监督 PCP（Oversight）                      |
| Disciplinary Review Committee (DRC)             | 纪律审查委员会            | 负责 Code and Standards 的纪律执行（Enforcement） |
| Professional Conduct Staff                      | 职业行为工作人员           | 负责 PCP 日常管理及调查（Investigation）            |
| Oversight                                       | 监督                 | Board of Governors 的核心职责关键词              |
| Enforcement                                     | 执行 / 实施            | DRC 的核心职责关键词                             |
| Investigation                                   | 调查                 | Professional Conduct Staff 的核心工作         |
| Integrity                                       | 诚信                 | CFA 职业道德核心价值之一                           |
| Competence                                      | 能力 / 胜任能力          | 专业人员应具备相应知识与技能                           |
| Diligence                                       | 勤勉                 | 工作中应尽到应有的谨慎与努力；也是 Standard V(A) 的关键词     |
| Material Nonpublic Information                  | 重大非公开信息            | 不得利用此类信息进行交易                             |
| Overconfidence                                  | 过度自信               | 道德决策的内部影响因素                              |
| Internal Influences                             | 内部影响因素             | 个人心理、认知等影响                               |
| Situational Influences                          | 情境影响因素             | 金钱、权威、同伴、业绩、时间等外部压力                      |
| Authority Pressure                              | 权威压力               | 来自上级或权威人士的压力                             |
| Peer Pressure                                   | 同伴压力               | 来自同事或群体的压力                               |
| Performance Pressure                            | 业绩压力               | 为达到业绩目标而产生的压力                            |
| Time Pressure                                   | 时间压力               | 时间紧迫导致判断受影响                              |
| Long-term Consequences                          | 长期后果               | 减少短期利益和情境压力影响的决策方法                       |
| Standard I(B) — Independence and Objectivity    | 标准 I(B)——独立性与客观性   | 专业判断不应受到不当利益或压力影响                        |
| Independence                                    | 独立性                | 保持专业判断不受不当影响                             |
| Objectivity                                     | 客观性                | 基于事实与合理判断，不偏袒                            |
| Reasonable Care and Judgment                    | 合理的谨慎与判断           | I(B) 要求会员运用合理谨慎和判断                       |
| Gifts, Benefits, Compensation, or Consideration | 礼物、利益、报酬或其他好处      | 若可能损害独立性与客观性，不得提供、索取或接受                  |
| Conflict of Interest                            | 利益冲突               | 个人或公司利益可能影响专业判断                          |
| External Pressure                               | 外部压力               | 上级、客户、雇主或商业关系施加的压力                       |
| Standard V(A) — Diligence and Reasonable Basis  | 标准 V(A)——勤勉调查与合理依据 | 投资分析、建议和行动必须有充分合理依据                      |
| Thoroughness                                    | 全面、彻底              | 分析投资时应进行充分调查                             |
| Reasonable and Adequate Basis                   | 合理且充分的依据           | 支持投资分析、建议或行动的基础                          |
| Appropriate Research and Investigation          | 适当的研究与调查           | V(A) 要求建议有研究调查支持                         |
| Investment Analysis                             | 投资分析               | 应勤勉、独立、全面地进行                             |
| Investment Recommendation                       | 投资建议               | 必须由合理且充分的依据支持                            |
| Investment Action                               | 投资行动               | 应有合理且充分的依据支持                             |
| Sell-side Analyst                               | 卖方分析师              | 通常为客户提供证券研究和投资建议                         |
| Investment Banking Department                   | 投资银行部门             | 承销、融资等业务；与研究部门可能存在利益冲突                   |
| Seasoned Equity Offering                        | 增发 / 后续股票发行        | 已上市公司再次发行股票融资                            |
| Overvalued                                      | 估值过高 / 被高估         | 分析师认为证券价格高于合理价值                          |
| Buy Recommendation                              | 买入建议               | 对证券提出买入评级或建议                             |

## GIPS｜全球投资业绩标准

| English Term | 中文释义 | 考试语境 / 记忆 |
|---|---|---|
| Global Investment Performance Standards (GIPS) | 全球投资业绩标准 | 规范投资业绩计算、展示与报告 |
| Firm | 公司 / 投资管理机构 | GIPS 合规主体 |
| Asset Owner | 资产所有者 | GIPS 也设有适用于符合定义的资产所有者的标准 |
| Total Firm Assets | 公司总资产 | 纳入公司承担投资管理责任的全部资产 |
| Investment Management Responsibility | 投资管理责任 | 判断资产是否计入 Total Firm Assets 的关键 |
| Discretionary Account / Portfolio | 全权委托账户 / 组合 | 管理人拥有投资决策权 |
| Non-discretionary Account / Portfolio | 非全权委托账户 / 组合 | 客户限制管理人的投资决策权 |
| Fee-paying Portfolio | 收费投资组合 | 实际收费的全权委托组合必须纳入至少一个 Composite |
| Non-fee-paying Portfolio | 非收费投资组合 | 全权委托的非收费组合可选择纳入 Composite |
| Advisory-only Assets | 仅咨询资产 | 仅提供建议、没有投资管理责任；不计入 Total Firm Assets |
| Composite | 组合群组 | 按相似策略、目标或授权归集的投资组合 |
| Composite Performance | 组合群组业绩 | 业绩展示层面；非全权委托组合不得纳入 |
| Firm-wide Basis | 公司整体范围 | GIPS 合规必须覆盖整个 Firm |
| Verification | 第三方验证 | 自愿；验证 Firm 的政策和程序 |
| Performance Examination | 业绩检查 | 针对特定 Composite 的业绩检查，与 Firm-wide Verification 不同 |
| Independent Third Party | 独立第三方 | 可执行 Verification |
| Cherry-Picking | 选择性展示 / 挑选业绩 | 只展示表现好的账户或组合，误导投资者 |
| Fair Representation | 公平呈现 | GIPS 的核心目标之一 |
| Full Disclosure | 充分披露 | GIPS 的核心目标之一 |
| Comparability | 可比性 | 提高不同机构业绩的可比程度 |
| Voluntary | 自愿的 | Verification 是自愿的 |
| Mandatory | 强制的 | Firm-wide Compliance 是要求，不应与 Verification 混淆 |
