# 高顿讲义整理规范

## 首要原则：保留原教案，不翻译

用户参加英文考试，需要用原教案的原始语言复习。**默认保留原文，不把英文翻译或归纳成中文，也不将原文改写成新的英文。** 原文是英文就保留英文，原文是中文就保留中文。

这一要求取代此前“中文完整复习版”的默认做法，适用于财报及后续各科讲义。用户明确另行要求翻译、总结或讲解时，才制作独立的辅助笔记；不把辅助内容混入原文。

## 仓库与目录

- 仓库：`YushuZhi96/CFA-Level-1-Notes`。
- 高顿资料只放在 `高顿资料/` 下；既有科目、个人笔记、总目录及模板不动。
- 原版 PDF 保持原文件名与原始字节，不用处理后的版本覆盖原件。
- 财报的文字版为 `财报-讲义原文.md`。每科保留原版 PDF、原文 Markdown 及必要图片资源，不另建“考点整理”或独立原图阅读页。
- 后续新科目默认使用 `<科目>-讲义原文.md`，不必预先创建空科目目录。

```text
高顿资料/
├── 讲义整理规范.md
└── <年份>-<课程名称>/
    └── <科目>/
        ├── <原始文件名>.pdf
        ├── <科目>-讲义原文.md
        └── assets/
            └── 讲义原页/
                ├── page-001.png
                └── ...
```

每科一份原文文字页，按原教案顺序提供章节导航及物理页码；不重排知识点，不合并或删去原页。年份只是归档分类，不代表已核对该年官方考纲。

## 默认交付：可搜索的原文文字版

用户需要从原教案提取文字，方便阅读、思考和标注。默认提供 `<科目>-讲义原文.md`：英文保留英文、中文保留中文，仅调整 Markdown 排版。**不以只有整页图片的文件代替文字提取。** 原文文字页直接链接对应原图，所需图片放在 `assets`，供逐页对照。

正文、题目与选项转为文字，公式转为经原图核对的 LaTeX，简单表格转为 Markdown 表格。复杂图示、空白 T 型账户及手写内容保留图；可辨认图中文字同时提取。每页保留原页链接和页码，原文有答案才录入答案。禁止为了让原文“更正确”而静默修正其原始表述。

## 原文展示方式

1. **图片型 PDF**：先 OCR 并对照原图核验，提取可搜索原文；同时保留原页面图片，保留公式、表格、图示、标注、例题、选项和空白练习区域。能直接提取整页原图时以无损方式保存；否则渲染完整页面，检查清晰度。注明图片展示不是可搜索文字转录。
2. **含可靠文本层的 PDF**：可在保持原语言、原措辞、原顺序的前提下转为 Markdown；不得翻译、改写、总结或自动纠错。复杂表格和图示保留原图。若用户强调原版式，仍优先原页展示。
3. **文字版核验**：OCR 只作识别辅助，逐页对照原图核验。无法确认的原文标注 `[OCR unclear]` 并关联原页，不猜测、不用中文释义替代。
4. 保留原讲义自身的错误或旧口径；仅在用户另行要求时将勘误写入独立辅助笔记，不能静默修改原文。
5. 不给空白题目自行填答案，不追加一句话理解、考试陷阱、自拟例题、学习进度或个人心得。

## 阅读页结构

- 元信息：`type: source-facsimile`（原页图片）或 `type: pdf-transcription`（忠实文字转录），科目、源文件、总页数、归档年份、更新日期、状态、标签。
- 标题及原版 PDF 相对链接。
- 简短说明：保持原教案语言和内容，明确采用图片还是文字方式。
- 章节目录，标题尽量沿用原教案，仅作导航。
- 每页 `### PDF p. N` 与 `<!-- PDF page N -->`，随后展示该页原图或原文。
- 完整性记录：总页数、页序、原件未修改、识别或清晰度限制。

## 操作与验收

1. 读取本规范，检查工作区、远端和来源版本，保留其他未提交改动。
2. 确认 PDF 页数、文字层及图像布局，建立章节与物理页码映射。
3. 提取或渲染整页，保持方向、分辨率和页序；不裁掉边缘文字或原标注。
4. 逐页核对文字、数字、公式、表格及阅读顺序；区分 OCR 识别错误与原讲义自身错误。检查数学语法及美元货币符号转义。若新增原图，直接提取时校验保存前后像素一致，渲染时检查清晰度。
5. 检查第 1 页至末页连续覆盖，所有图片、目录及 PDF 链接存在；抽查首、中、末及公式密集页的实际显示。
6. 确认正文没有新增翻译、改写、答案或讲解；原 PDF 校验值未变。
7. 只提交授权范围内的高顿资料变更并推送 GitHub，交付原文阅读页链接，准确说明是否支持文字搜索。

## 后续讲解与个人笔记

用户发来问题时可以在聊天中讲解。只有用户明确要求归档时才保存辅助笔记，并与讲义原文分开。个人理解和做题心得继续放原有个人笔记体系；不能把整理者的推导当作用户心得。
