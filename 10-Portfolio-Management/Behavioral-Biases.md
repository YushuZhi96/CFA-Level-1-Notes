# 行为金融学：15种行为偏差（Behavioral Biases）

[[10-Portfolio-Management/INDEX|← 返回投资组合管理目录]]

> **统一主笔记**：按 CFA 一级当前学习框架，将 15 种行为偏差集中在一份文件。原有三种偏差及 Base-Rate Neglect 专题保留为历史深度资料，不再分别作为 15 种偏差的主目录入口。本文件不保存完整试题与选项。

## 一、一句话理解与完整分类

行为金融学（Behavioral Finance）研究心理与认知因素如何影响投资者行为。行为偏差（Behavioral Biases）可能造成错误的预期、证券选择、风险配置和交易决策。

本次复习框架共 **15 种**：

| 类别 | 英文 | 数量 |
|---|---|---:|
| 信念固守偏差 | Belief Perseverance Biases（属于 Cognitive Errors） | 5 |
| 信息处理偏差 | Information-Processing Biases（属于 Cognitive Errors） | 4 |
| 情绪偏差 | Emotional Biases | 6 |
| **合计** | **9 Cognitive Errors + 6 Emotional Biases** | **15** |

### 两大类的总区别

- **Cognitive Errors（认知偏差）**：主要源于信息处理、推理、判断等认知机制的错误；往往可以通过数据、分析框架、检查清单和训练加以缓解（Moderate）。
- **Emotional Biases（情绪偏差）**：主要源于恐惧、后悔、自我评价、即时满足等情绪因素；较难仅靠纠正认知消除，有时需要适应与约束（Adapt），但不是完全无法改变。

**提醒**：这些偏差不是互斥的医学诊断。一个投资行为可能体现多个偏差，考试应依据题干**最明确的心理机制**判断。

## 二、信念固守偏差（Belief Perseverance Biases）——5种

### 1. Conservatism Bias（保守主义偏差）

**定义**：面对重要新信息时，仍过度坚持旧观点，对信念或预测更新不足（Insufficient Updating / Underreaction）。

**例子**：公司近期基本面显著恶化，但分析师继续沿用多年以前的增长假设，不合理地维持原估值。

- 识别词：**Slow to update beliefs / Cling to prior views / Underreact to new evidence**。
- 常见后果：估值滞后、对真实环境变化反应不足。
- 缓解：定期重估核心假设；明确哪些新证据应触发修正。
- **边界**：合理地继续持有不等于偏差；重点看是否充分评估新证据。

### 2. Confirmation Bias（确认偏差）

**定义**：优先搜集、解释或记住支持原有观点的证据（Supporting Evidence），忽略或贬低相反信息（Contradictory Evidence）。

**例子**：坚持看好某股票，只阅读看多报告，对有事实依据的负面研究视而不见。

- 识别词：**Seek confirming evidence / Selective information / Ignore contrary views**。
- 常见后果：判断单边化、风险识别不足。
- 缓解：主动搜集反证，设定可推翻原判断的条件。
- 与 Conservatism 区别：**确认偏差是选择性处理信息；保守主义是面对信息后更新不足**。

### 3. Representativeness Bias（代表性偏差）

**定义**：因对象与某个典型形象或类别相似（Resemblance / Stereotype），就推断其特征或未来表现，而可能忽略基础概率与样本信息。

**例子**：某公司连续几个季度高速增长，就据此断言它一定能成为持续十年的明星企业。

- 识别词：**Looks like a winner / Stereotype / Small sample / Ignore base rates**。
- 常见后果：以偏概全、对“看起来很像”的对象做过度推断。
- 常见表现：**Base-Rate Neglect（基础比率忽视）**——忽略同类企业历史表现或参考类别的基础概率。
- 缓解：结合 **Outside View（外部视角）** 的参考类别统计数据与 **Inside View（内部视角）** 的企业特定证据。

深入阅读：[[Base-Rate-Neglect-Outside-Inside-View|基础比率忽视与内外部视角]]。

### 4. Illusion of Control Bias（控制幻觉偏差）

**定义**：高估自己对随机事件、市场结果或实际上难以控制的因素的影响力（Perceived Control）。

**例子**：投资者认为反复盯盘、频繁调仓就能控制股价短期变化，于是增加交易次数。

- 识别词：**Believe one can control outcomes / Control over randomness / Excessive trading**。
- 常见后果：过度交易（Excessive Trading）、不必要的交易成本、风险承担过多。
- 缓解：区分可控的交易流程与不可控的市场结果，用长期证据评估策略，而不是以操作次数衡量能力。
- 与 Overconfidence 区别：控制幻觉强调**对结果控制能力的高估**；过度自信强调**高估知识、判断或预测能力**。两者都可能导致过度交易。

### 5. Hindsight Bias（后见之明偏差）

**定义**：事件发生后，认为该结果在事前就很明显、早该被预测（Knew-it-all-along Effect）。

**例子**：某公司业绩暴雷后，投资者声称“我早就知道它一定会出问题”，却拿不出事前预测记录。

- 识别词：**Knew it all along / After the fact / Outcome seemed predictable**。
- 常见后果：低估预测难度、高估过去判断的准确性、错误学习。
- 缓解：保存决策日志、事前概率预测及当时掌握的信息。

## 三、信息处理偏差（Information-Processing Biases）——4种

### 6. Anchoring and Adjustment Bias（锚定与调整偏差）

**定义**：过度依赖某个最初参考值（Anchor），后续调整不充分（Insufficient Adjustment）。

**例子**：以每股100元买入股票，股价跌至70元且基本面变化，仍以原买入价100元作为合理价值的主要依据。

- 识别词：**Initial price / Reference point / Anchor / Insufficient adjustment**。
- 常见后果：估值扭曲、不愿意依据新信息调整目标价。
- 缓解：独立重新估值，避免先显示无关参考价。
- 与 Conservatism 区别：**Anchoring 被特定起始数字锚定；Conservatism 是固守旧信念**。

### 7. Mental Accounting Bias（心理账户偏差）

**定义**：按资金来源或用途将可替代的资金分成心理账户，并采取可能不一致的消费、储蓄或投资规则；忽视资金的可替代性（Fungibility）和整体财富（Total Wealth）。

**例子**：工资严格储蓄，奖金只作退休储备，投资盈利却被当作“额外的钱”而随意承担高风险。

- 识别词：**Different sources of money / Separate mental buckets / Different uses of funds**。
- 常见后果：孤立配置各账户，忽略整体资产风险；可能出现 **House Money Effect（赌场资金效应）**。
- 缓解：从 **Total Portfolio（整体投资组合）** 角度综合评价风险、目标和约束。
- **边界**：为不同用途分设银行账户可以是合理预算管理，不是只要分账户就一定存在非理性偏差。

### 8. Framing Bias（框架效应偏差）

**定义**：同一经济问题因为表达或呈现方式不同（Different Presentation / Framing），引发不同决策。

**例子**：投资者对“90% 成功概率”和“10% 失败概率”的本质等价方案作出明显不同的风险选择。

- 识别词：**Different wording / Gain frame vs loss frame / Same facts, different presentation**。
- 常见后果：风险偏好随语言或参考框架改变。
- 缓解：将选择还原为相同金额、相同概率与相同时间尺度的表达。
- 与 Mental Accounting 区别：**Framing 关注信息的表达方式；Mental Accounting 关注资金心理分类**。

### 9. Availability Bias（可得性偏差）

**定义**：过度重视容易回忆、容易取得或印象鲜明的信息（Readily Available / Easily Recalled Information），而不是按照总体数据合理判断。

**例子**：某机构投资者身边许多同事有 CFA 资格，因此直接推断整个同类行业的 CFA 持证人比例都很高。

- 识别词：**Easy to recall / Vivid events / Recent examples / Narrow range of experience**。
- 可能来源：**Retrievability（容易回忆）**、**Categorization（分类）**、**Narrow Range of Experience（狭窄经验范围）**、**Resonance（与自身经历产生共鸣）**。
- 常见后果：因接触信息局限而高估某类事件的频率或普遍性。
- 缓解：扩大样本、使用有代表性的总体数据，检验信息来源。
- 与 Representativeness 区别：**Availability 因为例子容易想起而相信；Representativeness 因为对象像某个典型类别而相信**。

## 四、情绪偏差（Emotional Biases）——6种

### 10. Loss Aversion Bias（损失厌恶偏差）

**定义**：相同金额的损失造成的心理痛苦通常大于同等收益带来的快乐（Losses Loom Larger Than Gains）。

**例子**：投资者为了避免承认亏损而长期持有亏损股，却过早出售小幅盈利的股票。

- 识别词：**Pain of loss / Reluctant to realize losses / Disposition effect**。
- 常见后果：处置效应（Disposition Effect），过早卖出赢家、过久持有输家。
- 缓解：预先设定投资论点与卖出条件，以未来现金流和预期收益决定持有与否。

### 11. Overconfidence Bias（过度自信偏差）

**定义**：高估自身的判断、知识、预测准确度或信息质量。

**例子**：投资者相信自己的选股准确率远高于事实，不断加仓少数熟悉股票，并频繁交易。

- 识别词：**Overestimate ability / Excessive certainty / Too narrow confidence intervals**。
- 常见后果：过度交易、组合过度集中、低估风险。
- 缓解：记录预测误差，做事后校准，对仓位与风险暴露设限。
- 与 Illusion of Control 区别：Overconfidence 侧重**能力评估过高**；Illusion of Control 侧重**认为能够控制结果**。

### 12. Self-Control Bias（自我控制偏差）

**定义**：短期诱惑或即时满足需求压过长期财务目标（Short-term Gratification vs Long-term Goals）。

**例子**：明知需要为退休储蓄，仍长期把计划投资的钱用于当期消费。

- 识别词：**Immediate spending / Fail to save / Short-term temptation**。
- 常见后果：储蓄不足、长期投资计划难以落实。
- 缓解：自动定投、强制储蓄、预先承诺（Commitment Devices）。

### 13. Status Quo Bias（现状偏差）

**定义**：倾向维持当前状态或默认选择（Status Quo / Inertia），即便变化可能更合适。

**例子**：投资组合长期偏离风险目标，投资者只是因为“不想改变”而拒绝重新配置。

- 识别词：**Keep current allocation / Default choice / Inertia / Resistance to change**。
- 常见后果：组合长期偏离风险目标、错失改善配置的机会。
- 缓解：制定定期复核和再平衡机制。
- 与 Conservatism 区别：Status Quo 更强调对**现状或行动本身的惯性**，不一定有新信息更新不足。

### 14. Endowment Bias（禀赋偏差）

**定义**：仅因自己拥有某项资产（Ownership），就赋予它高于没有持有时的价值。

**例子**：因继承而持有某股票，对其估值高于市场上同等风险与现金流资产的客观价值。

- 识别词：**Value it more because owned / Ownership / Reluctance to sell owned asset**。
- 常见后果：持有不适当资产、过度集中。
- 缓解：反问“如果现在持有的是现金，还会按当前价格主动买入吗？”

### 15. Regret Aversion Bias（后悔厌恶偏差）

**定义**：因担忧未来决策结果导致懊悔（Fear of Regret），而回避采取本应基于分析作出的行动。

**例子**：投资者认为有充分依据应调整持仓，但担心调整后股价上涨、自己会后悔，因此迟迟不做决定。

- 识别词：**Fear of regret / Avoid making decision / Herd behavior**。
- 常见后果：错失理性调整、追随大众以减轻个人后悔的心理负担。
- 缓解：明确事前决策标准，并用过程质量而非事后结果评价决策。
- 与 Loss Aversion 区别：**Loss Aversion 是损失的痛苦较大；Regret Aversion 是害怕自己决策造成的后悔**。

## 六、考试高频易混淆对照

| 常见混淆 | 如何判断 |
|---|---|
| Conservatism vs Anchoring | 固守**旧信念** vs 被**特定初始参考值**影响 |
| Conservatism vs Confirmation | **更新不足** vs **有选择地获取/接受证据** |
| Availability vs Representativeness | **容易想起例子** vs **看起来符合典型类别** |
| Illusion of Control vs Overconfidence | 高估**结果可控性** vs 高估**个人能力或判断** |
| Mental Accounting vs Framing | 对资金进行**心理分类** vs 对信息的**表达形式**敏感 |
| Loss Aversion vs Regret Aversion | 主要害怕**损失本身** vs 主要害怕**事后懊悔** |
| Status Quo vs Conservatism | 因**现状惯性**不改变 vs 面对**新证据仍旧观点不变** |

### 典型后果的提示词

- **Excessive Trading（过度交易）**：优先考虑 Illusion of Control / Overconfidence；再看题干是“以为可控”还是“自信能预测”。
- **Narrow Range of Experience（狭窄经验范围）**：优先考虑 Availability。
- **Old view despite new evidence（新证据出现仍固守旧看法）**：Conservatism。
- **Only positive research（只选支持性研究）**：Confirmation。
- **Money is money, but different sources treated differently（同样的钱按来源区别对待）**：Mental Accounting。
- **I knew it would happen（我早知道会如此）**：Hindsight。

## 七、理解上的两个特别提醒

### 1. 行为偏差不等于投资结果一定错误

例如继续持有股票、设置专门的退休账户，或进行较多交易，单凭行为本身不能证明偏差。应根据**信息处理与决策机制**判断，而不是只看动作或结果。

### 2. Cognition 与 Emotion 的纠偏策略不同

- 认知偏差：更适合用基准数据、反证、事前记录、概率推理和决策检查清单**缓解（Moderate）**。
- 情绪偏差：可能还需要自动化储蓄、资产配置限制、交易冷静期等制度安排，必要时**适应（Adapt）**投资者的行为特征。
