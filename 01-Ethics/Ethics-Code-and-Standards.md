# 道德、道德规范与行为准则（Ethics, Code of Ethics & Standards of Conduct）

## 三个概念

### 1. Ethics（道德）

关于正确与错误、好与坏的道德原则和价值观。

- **Moral and ethical principles**：道德与伦理原则
- **Good or bad / Right or wrong**：好与坏 / 对与错

### 2. Code of Ethics（道德规范）

特定社会群体或组织以书面原则形式，对成员应履行的义务和禁止的行为作出总体规定。

- **Written set of principles**：书面原则集合
- **Specific communities or social groups**：特定社区或社会群体
- **Obligatory conduct**：必须履行的行为 / 义务
- **Forbidden conduct**：禁止的行为
- **General guide to action**：行动的总体指导原则

### 3. Standards of Conduct（行为准则）

将道德规范进一步具体化，规定成员必须达到的最低可接受行为标准。

- **Minimally acceptable behavior**：最低可接受行为
- **Benchmark**：行为基准 / 衡量标准
- **Specific rules or requirements**：具体规则或要求

## 三者关系

**Ethics（道德原则） → Code of Ethics（群体书面道德规范） → Standards of Conduct（具体行为标准）**

记忆：
- Ethics：什么是对、什么是错。
- Code of Ethics：这个群体提倡什么、要求什么、禁止什么。
- Standards of Conduct：成员具体应该怎样做，最低行为底线是什么。

## 易混点

- **Code of Ethics** 强调特定群体的书面原则，以及义务和禁止事项。
- **Standards of Conduct** 强调可执行的具体行为要求和最低标准。
- **Laws（法律）** 由政府或有权机构制定，适用于相应司法管辖区（Jurisdiction）内的个人和实体；不要与某个职业群体自己的 Code of Ethics 混淆。
