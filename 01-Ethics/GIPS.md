# 全球投资业绩标准（GIPS）

## 一句话理解

GIPS（Global Investment Performance Standards，全球投资业绩标准）规范投资业绩的计算、展示和报告，目的是提高**公平性（Fair Representation）、充分披露（Full Disclosure）和可比性（Comparability）**，防止选择性展示业绩（Cherry-Picking）。

**核心记忆：公司整体实施；公司总资产按投资管理责任统计；组合业绩按全权委托资格归集；Verification 自愿。**

## 1. 适用主体与公司范围

- **Firm（投资管理公司）**：必须符合 GIPS 对 Firm 的定义，并承担投资管理责任，才能以该 Firm 名义宣称合规。
- **Asset Owners（资产所有者）**：GIPS 也设有适用于符合定义的资产所有者的标准。
- **Firm-wide Basis（公司整体范围）**：合规必须覆盖整个 Firm，不能只挑选表现好的部门、基金或账户。

## 2. Total Firm Assets（公司总资产）

计算公司总资产时，应纳入公司承担**投资管理责任（Investment Management Responsibility）**的全部资产：

- Discretionary（全权委托）和 Non-discretionary（非全权委托）均纳入。
- Fee-paying（收费）和 Non-fee-paying（非收费）均纳入。
- **Advisory-only Assets（仅咨询资产）**：公司仅提供建议、没有投资管理责任的资产，不计入。

记忆：**Total Firm Assets 看是否承担投资管理责任，不以是否全权委托或是否收费来排除。**

## 3. Composite（组合群组）与业绩纳入规则

**Composite**：按照相同或相似投资策略（Strategy）、投资目标（Objective）或投资授权（Mandate）管理的一个或多个投资组合归为一组，用于展示该策略的业绩。

| 账户类型 | 是否纳入 Composite |
|---|---|
| Actual fee-paying discretionary portfolios | 必须纳入至少一个 Composite |
| Non-fee-paying discretionary portfolios | 可以选择纳入 |
| Non-discretionary portfolios | 不得纳入 |

记忆：**收费 + 全权委托必须纳入；非收费 + 全权委托可选；非全权委托不得纳入。**

## 4. Verification（第三方验证）

**Verification 是自愿的（Voluntary），不是强制的（Mandatory）。**

- 由独立第三方（Independent Third Party）执行。
- 验证对象是整个 Firm 的 GIPS 合规政策和程序。
- 不代表投资业绩优秀，也不保证未来收益。
- **Performance Examination（业绩检查）**针对特定 Composite，与 Firm-wide Verification 不同。

## 5. 常见考试陷阱

1. **Firm-wide：** 不能只让业绩好的部门或账户宣称合规。
2. **Total Firm Assets：** 不要排除 Non-discretionary 或 Non-fee-paying 资产；关键是公司是否承担投资管理责任。
3. **Composite：** 不得纳入 Non-discretionary portfolios；Actual fee-paying discretionary portfolios 必须纳入至少一个 Composite。
4. **Verification：** 自愿，不是强制。
5. **Advisory-only：** 仅提供咨询、没有投资管理责任的资产，不计入 Total Firm Assets。
6. **Cherry-Picking：** 不得只展示表现好的组合。

## 考前速记

| 考点 | 结论 |
|---|---|
| GIPS 目标 | 公平呈现、充分披露、提高可比性 |
| 合规范围 | Firm-wide Basis |
| Total Firm Assets | 纳入所有承担投资管理责任的资产 |
| Advisory-only Assets | 不计入 Total Firm Assets |
| Composite | 按相似策略 / 目标 / 授权归集 |
| 收费全权委托组合 | 必须纳入至少一个 Composite |
| 非收费全权委托组合 | 可选择纳入 Composite |
| 非全权委托组合 | 不得纳入 Composite |
| Verification | 自愿（Voluntary） |

**一句话背诵：规模看投资管理责任；业绩看全权委托资格；收费组合必须纳入，非收费全权委托可选，非全权委托不得纳入；验证自愿。**
